Mathematical Core

1. Candidate Match Score & Rubric Algorithm

How candidate resumes are evaluated against job sessions. CareerSphere uses a dynamic multi-dimensional weight vector formula:

Weighted Match Formula:

Score = (S_match * W_skills) + (E_match * W_exp) + (L_match * W_loc) + (Edu_match * W_edu)

Where weights (W_skills, W_exp, W_loc) sum to 1.0 (configured by recruiter per session).

Python — Candidate Match Logic 
# From backend candidate scoring agent
def calculate_match_score(candidate_profile, job_criteria):
    weights = job_criteria.get("weights", {"skills": 0.5, "experience": 0.3, "location": 0.2})
    
    # 1. Skill Intersection Score (Semantic + Substring)
    req_skills = set(s.lower() for s in job_criteria.get("required_skills", []))
    cand_skills = set(s.lower() for s in candidate_profile.get("skills", []))
    matched_skills = req_skills.intersection(cand_skills)
    skill_score = (len(matched_skills) / len(req_skills)) * 100 if req_skills else 100
    
    # 2. Experience Ratio Score
    req_exp = job_criteria.get("min_experience", 0)
    cand_exp = candidate_profile.get("years_experience", 0)
    exp_score = 100 if cand_exp >= req_exp else (cand_exp / req_exp) * 100 if req_exp > 0 else 100
    
    # 3. Location Match
    loc_score = 100 if candidate_profile.get("is_remote") or location_match else 50

    # Final Weighted Score Vector
    final_score = (skill_score * weights["skills"]) + (exp_score * weights["experience"]) + (loc_score * weights["location"])
    return round(final_score, 1)
PDF Geometry Extraction

2. Geometry-Aware Two-Column PDF Splitter

Standard PDF extractors read text horizontally across the entire page width, corrupting two-column resume sections. CareerSphere uses vertical bounding-box projection analysis in PyMuPDF:

Python — Column Splitter Algorithm 
# From advanced_ats_parsing_agent.py
for x in range(start_x, end_x, 5):
    crossings = 0
    for b in blocks:
        x0, y0, x1, y1 = b[0], b[1], b[2], b[3]
        if y0 >= 120 and y1 <= page_height - 80:
            if x0 < x < x1:
                crossings += 1  # Bounding box intersects vertical split line x

    if crossings < min_crossings:
        min_crossings = crossings
        best_x = x  # Optimal divider x coordinate with minimal text box cuts

# Separate left column vs right column blocks cleanly
left_blocks = [b for b in blocks if (b[0] + b[2]) / 2.0 < best_x]
right_blocks = [b for b in blocks if (b[0] + b[2]) / 2.0 >= best_x]
Frontend Visualization

3. Dynamic SVG Score Ring Graph Rendering

How score percentage circles and progress bars are computed smoothly in React without external heavy graphics libraries.

SVG Circumference Formula:

C = 2 * π * r   ⇒   strokeDashoffset = C - (C * score / 100)
JSX — React SVG Animated Ring 
// From frontend ResumePreview.jsx & Landing pages
const radius = 27;
const circumference = 2 * Math.PI * radius; // ~169.6px
const offset = circumference - (circumference * overallScore) / 100;

return (
  <svg className="w-16 h-16 transform -rotate-90">
    <circle cx="32" cy="32" r={radius} stroke="rgba(37, 99, 235, 0.1)" strokeWidth="4" fill="transparent" />
    <circle
      cx="32" cy="32" r={radius}
      stroke="rgb(37, 99, 235)" strokeWidth="4" fill="transparent"
      strokeDasharray={circumference}
      strokeDashoffset={offset}
      className="transition-all duration-500 ease-out"
    />
  </svg>
