System Architecture Overview

CareerSphere is structured as a decoupled multi-tier system: React SPA frontend, Django REST Framework application server, Gemini 2.5 LLM Multi-Agent network, and asynchronous Celery/Redis queue.

AI Engine Architecture

Multi-Agent AI Network & RotateLLMClient

Rather than a monolithic prompt, CareerSphere delegates tasks to autonomous specialized agents. The RotateLLMClient manages key rotation to eliminate API rate-limits and optimize token costs.

AGENT 01

ATS Parser Agent

PyMuPDF coordinate block vertical splitting + Gemini 2.5 Flash. Extracts structured JSON resume profiles.

AGENT 02

Inference Agent

Analyzes raw Job Descriptions to infer missing skills, experience bounds, salary ranges, and seniority levels.

AGENT 03

Criteria & Scoring Agent

Computes multi-dimensional vector match scores between applicant profiles and company job rubrics.

AGENT 04

Interview Bot Agent

Generates custom MCQ and Coding questions per candidate skill gap, evaluating responses in real-time.

AGENT 05

Notification Agent

Monitors score updates, triggers email alerts for top match candidates (>85%), and posts webhooks.

MANAGER

RotateLLMClient

Thread-safe round-robin API key manager with automatic failover and exponential retry backoff.

Data Lifecycle

End-to-End Candidate Application Lifecycle

1. PDF Resume Upload
User uploads resume. Standard HTTP multipart POST sent to /api/seeker/upload-resume/ with JWT bearer token.
2. Geometry-Aware Text Extraction
AdvancedAtsParsingAgent.extract_text_column_aware() analyzes PDF layout, detects two-column splits, and preserves section order.
3. Structured LLM Parsing
Resume text sent to Gemini 2.5 Flash via RotateLLMClient. Transformed into canonical JSON schema (skills, exp, education).
4. Job Matching & Rubric Evaluation
Job criteria weights evaluated against parsed resume data. Vector scores computed for Skills, Experience, Location & Salary.
5. Persistence & Recruiter Alert
Candidate record saved in PostgreSQL. If score ≥ 80%, high-match email notification queued via Celery to company recruiters.
