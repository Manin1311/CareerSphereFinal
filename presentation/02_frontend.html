02. Frontend Architecture — React 18 + Vite + Zustand
Component Structure · State Management · Routing · UI Flow
Frontend Technology Stack
The CareerSphere frontend is a React 18 Single Page Application (SPA) bundled using Vite for near-instant HMR and sub-second production builds. State management uses Zustand — a lightweight flux-style store — for persisting JWT tokens, user profiles, and theme preferences without Redux boilerplate. The UI uses a hybrid CSS approach: Tailwind utility classes for layout and vanilla CSS variables for consistent design tokens across the application.

State Management with Zustand

authStore.js — Global Application State

JavaScript import { create } from 'zustand'; import { persist } from 'zustand/middleware'; const useAuthStore = create( persist( (set, get) => ({ // ── Auth State ── token: null, // JWT access token refreshToken: null, user: null, // { id, email, full_name, tier, avatar_path } role: null, // 'seeker' | 'recruiter' | 'admin' // ── Actions ── setAuth: (token, refreshToken, user, role) => set({ token, refreshToken, user, role }), logout: () => set({ token: null, refreshToken: null, user: null, role: null }), updateUser: (partial) => set({ user: { ...get().user, ...partial } }), }), { name: 'careersphere-auth', // localStorage key partialize: (state) => ({ token: state.token, refreshToken: state.refreshToken, user: state.user, role: state.role, }), } ) ); export default useAuthStore;
Axios API Client with JWT Interceptors
JavaScript — portalApi.js import axios from 'axios'; import useAuthStore from './authStore'; const portalApi = axios.create({ baseURL: `${import.meta.env.VITE_API_URL}/api`, headers: { 'Content-Type': 'application/json' }, timeout: 30000, }); // ── Request Interceptor: Attach JWT bearer token ── portalApi.interceptors.request.use((config) => { const token = useAuthStore.getState().token; if (token) { config.headers.Authorization = `Bearer ${token}`; } return config; }); // ── Response Interceptor: Handle 401, trigger refresh ── portalApi.interceptors.response.use( (response) => response, async (error) => { if (error.response?.status === 401) { // Token expired — attempt silent refresh useAuthStore.getState().logout(); window.location.replace('/login'); } return Promise.reject(error); } ); export default portalApi;
Key Component Deep Dives

📊 SVG Match Score Ring (UserJobDetail)

The circular progress indicator on job detail pages is a pure SVG implementation. Radius = 27px. Circumference = 2π × r = ~169.6px. strokeDashoffset = circumference − (circumference × score / 100). Animates via CSS transition on the SVG stroke property. No external chart libraries required.

💰 Salary Parser in UserJobs (parseSalary)

The salary filter function parses any salary string (₹18–32 LPA, $80k–120k, ₹18,000/month) into numeric min/max values. Expands "k" notation (18k → 18000), "lakh/lpa" notation (18 LPA → 1,800,000). Monthly salaries detected via "/month" suffix and multiplied by 12. Cross-currency normalization to USD for comparison.

✏️ Resume Editor (ResumeEditor.jsx — 102KB)

The largest component in the codebase. Manages a comprehensive resume JSON object in local state, provides inline editing for all sections (experience bullet points, skill chips, project tech stack), live preview via template components, and triggers debounced autosave to the backend. Templates render identical HTML for both preview and PDF export.

🎤 MockInterviewPage (AI Sandbox)

Users select job domain (Frontend, Backend, DSA, System Design, ML). API call generates 5–10 questions via the Interview Agent. User answers via text or speech (Web Speech API). Answers posted to backend for AI scoring. Results page shows per-question score, ideal answer, and improvement recommendations. Supports practice mode without submitting.

📁 VerificationModal (OTP Flow)

Handles both email OTP (6-digit code sent via Django email backend) and phone OTP (if configured). Implements a 60-second resend countdown timer using useRef + setInterval. Auto-focuses the next OTP digit input on entry. Validates the 6-digit code against the backend verification endpoint and updates email_verified / phone_verified flags on success.

🏢 UserCompanyDetail (Company Page)

Fetches company profile including logo_path (CDN URL or uploaded image), rating aggregate, about text, open jobs (active sessions), and review list. Follow/unfollow stores company ID in the seeker's resume_data.followed_companies JSON array. Review creation submits to the reviews endpoint with rating (1–5) and text content.

Job Application User Flow (Frontend)
1
Browse Jobs (UserJobs.jsx) User filters jobs by salary range, skills required, location. parseSalary() converts all salary formats to numeric LPA for comparison. Filters applied client-side on the jobs array fetched from /api/seeker/jobs/.
2
View Job Detail (UserJobDetail.jsx) Full job description rendered. If the seeker has a resume uploaded, an AI match score is displayed via the SVG ring. Score fetched from /api/seeker/jobs/:id/match-score/ using the seeker's parsed resume data.
3
Apply (UserApply.jsx) Seeker writes an optional cover note, accepts terms, and submits. POST to /api/seeker/apply/. Backend creates Candidate + JobApplication records, triggers email confirmations via Celery task, checks match threshold for high-match alert.
4
Track Status (UserApplications.jsx) Seeker sees all applications with status badges: applied / shortlisted / rejected / hired. Shows current interview round, next scheduled round, and match score breakdown. Clicking "View Feedback" shows matched_skills and missing_skills from the match_details JSON.
5
Complete Interview Rounds When recruiter advances the candidate, a notification is sent and the seeker can access the interview round UI (MCQRound or CodingRound components). Submitting answers triggers async backend scoring. Results are persisted in ApplicantRoundAttempt records.
⚡ Performance Note

The React frontend bundles to under 25KB gzipped for critical path JavaScript using Vite's automatic code splitting. Heavy pages like ResumeEditor and MockInterviewPage are lazy-loaded via React.lazy() + Suspense, ensuring the initial page load is fast regardless of the total bundle size (which exceeds 10MB including all vendor libraries).
