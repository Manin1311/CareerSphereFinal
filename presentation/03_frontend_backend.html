Document 03 — Tech Stack

Full-Stack Technology Ecosystem

CareerSphere leverages modern software engineering standards with React 18 SPA for client experience and Django REST Framework with Celery for backend AI orchestration.

Frontend Technologies

React 18 Vite Tailwind CSS Zustand Lucide Icons Framer Motion Recharts Axios
  • Single Page Application (SPA) compiled via Vite.
  • Atomic CSS design system via Vanilla CSS variables + Tailwind.
  • Persistent local & JWT session state managed by Zustand.
  • Interactive SVG graph rendering for match score breakdown.

Backend & AI Infrastructure

Django 4.x Django REST Framework Gemini 2.5 Flash PyMuPDF (fitz) pdfplumber Celery Redis PostgreSQL
  • Modular REST API views for job listings, seeker profiles, and recruiter dashboards.
  • Custom RotateLLMClient to switch Gemini API keys seamlessly.
  • Geometry-aware two-column PDF text extraction pipeline.
  • Asynchronous Celery tasks for heavy LLM inference & email alerts.

Data Synchronization

State Management & API Integration Flow

1. Auth & JWT Store

Dual JWT token auth (Seeker vs Recruiter). Access tokens attached automatically via Axios request interceptors. Expired tokens trigger refresh cycles.

2. Non-Blocking Async Polling

When parsing a resume, frontend dispatches job request, receives task ID, and polls /api/seeker/ats-status/ while displaying animated loaders.

3. Optimistic UI Updates

Resume edit changes render instantly in ResumePreview.jsx via local Zustand state before debouncing updates to the Django backend.
