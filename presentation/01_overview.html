What is CareerSphere?
CareerSphere is a full-stack, enterprise-grade recruitment intelligence platform that connects job seekers and companies through an autonomous multi-agent AI pipeline. Unlike traditional HR software that relies on rigid keyword filters, CareerSphere deploys a network of specialized LLM agents — each responsible for a distinct task: parsing resumes, inferring job requirements, scoring candidate matches, generating dynamic interview questions, and predicting hire probability using historical ML models. The system eliminates manual screening bottlenecks, providing instant, transparent, explainable candidate rankings directly in an interactive recruiter dashboard.

Problem Statement & Solution

❌ Problems in Traditional Hiring

  • ⚠️ Standard ATS parses PDF text linearly — shattering two-column resume layouts and losing critical skill data.
  • ⚠️ Keyword-only matching rejects qualified candidates who use synonyms like "Node" instead of "Node.js".
  • ⚠️ Recruiters spend 20–30 hours per role manually reviewing resumes — highly inefficient at scale.
  • ⚠️ No explainability: candidates don't know WHY they were rejected or what skills are missing.
  • ⚠️ Job seekers have no way to practice dynamic, personalized interview preparation before applying.
  • ⚠️ Single API key approaches fail under LLM rate-limits, causing full-system downtime.

✅ CareerSphere Solutions

  • ✨ Geometry-aware bounding-box column detection preserves two-column resume structure perfectly.
  • ✨ Sentence transformer embeddings + TF-IDF cosine similarity catches synonyms and conceptual matches.
  • ✨ Fully automated pipeline: upload → parse → match → rank → notify in under 5 seconds.
  • ✨ Detailed match breakdown returned: skill_score, exp_score, location_score, missing_skills listed.
  • ✨ AI Interview Sandbox generates personalized MCQ and coding challenges based on job requirements.
  • ✨ RotateLLMClient pools multiple Gemini/Groq keys with auto-failover and retry backoff.

Core Features & Modules
📄
Advanced ATS Resume Parser
AI

Three-tier PDF extraction engine using PyMuPDF column detection. Identifies bounding-box vertical split for two-column layouts. Fallback to pdfplumber for font-embedded PDFs. LLM post-processing converts raw text into structured JSON (summary, skills, experience, education, projects).

🎯
Semantic Candidate Matching
ML

Uses sentence-transformer embeddings to compute cosine similarity between candidate skills and job requirements. Falls back to TF-IDF char-level n-gram vectorization. Returns skill_score, experience_score, location_score, and a final weighted match_score (0–100).

🤖
Skill Inference Agent
AI

Analyzes job descriptions via Gemini 2.5 Flash to infer unstated required skills, seniority level, experience bounds, and salary ranges. Extracts structured criteria JSON for use in candidate evaluation rubrics without any manual recruiter configuration.

💬
AI Interview Engine
AI

Generates role-specific MCQ questions, coding challenges, and behavioural interview prompts dynamically per candidate skill gap. Scores answers automatically and progresses candidates through multi-round pipelines (Screening → Technical → HR Round).

📊
Recruiter Analytics Dashboard
CORE

Companies post hiring sessions, define rubric weight vectors (skills/exp/location), view ranked applicant lists with match scores, advance candidates through interview rounds, and download AI-generated screening reports with one click.

🔑
RotateLLMClient (Key Manager)
INFRA

Thread-safe singleton that maintains pools of Gemini API keys and Groq keys. Tracks per-key daily quota exhaustion aligned to Google's Pacific Time reset cycle. Auto-rotates to next available key on 429 errors. Parses retry-after durations from error messages.

📝
Resume Builder & PDF Renderer
PORTAL

Job seekers use a live resume editor with 8+ professional templates. Templates rendered to pixel-perfect PDF using ReportLab / WeasyPrint. ATS Compatibility Agent scores the resume against 40+ criteria and suggests concrete improvements.

🔔
Notification & Email Pipeline
CORE

Automated email triggers for: application confirmation, high-match candidate alert (≥80%), status change notifications, interview invitation, and weekly digest. Delivered via Django email backend through async Celery task workers.

💡 Key Design Principle

Every component of CareerSphere is asynchronous-first: heavy AI tasks are processed by Celery workers backed by Redis, keeping the React frontend fully responsive with live progress indicators while parse/score operations run concurrently in the background.
