Problem & Industry Context

The Problem & Core Project Objectives

Traditional Applicant Tracking Systems (ATS) rely on rigid keyword matching, penalize multi-column PDF layouts, and require excessive manual screening by recruiters. CareerSphere solves this with autonomous AI agents.

Legacy System Flaws

  • Standard PDF parsers mangle two-column resume text.
  • Exact keyword filters reject qualified candidates missing trivial synonyms.
  • Recruiters spend 20+ hours per job listing manually reviewing resumes.
  • Lack of real-time practice and instant feedback for job seekers.

CareerSphere Solution

  • Column-aware PDF layout parser using coordinate geometric bounding boxes.
  • Multi-agent semantic skill inference via Gemini 2.5 Flash LLM rotation.
  • Automated candidate match score calculation with customizable weight vectors.
  • Integrated AI Interview sandbox with real-time feedback & dynamic questions.
Core Pillars

Key Architectural Features

Advanced ATS Parsing

3-tier fallback parser (PyMuPDF blocks → PyMuPDF plain text → pdfplumber) ensuring zero data loss even on complex custom resume templates.

Multi-Agent AI Network

Decoupled LLM agents specialized in skill inference, job requirement criteria extraction, resume scoring, and live technical interviews.

Dynamic Match Analytics

Multi-dimensional match score breakdown (Skills, Experience, Location, Pay) rendered dynamically with interactive SVG charts.

Interactive Candidate Portal

Job seekers can upload resumes, generate live ATS compatibility reports, edit profile details, and practice automated interview rounds.

Recruiter Dashboard

Companies post hiring sessions, set evaluation rubric weights, monitor applicant rankings, and automate candidate round progression.

Enterprise Security & Limits

JWT-based dual authentication (Seeker & Developer/Recruiter), rate limiting, webhook triggers, and automated notification pipeline.
