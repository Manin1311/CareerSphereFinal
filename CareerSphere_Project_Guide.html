1. Executive Project Overview

CareerSphere is an Autonomous Multi-Agent AI Recruitment & Smart Proctoring Ecosystem designed to streamline candidate sourcing, automated screening, dynamic multi-stage assessment (MCQ, Live Coding, and Voice AI Interviews), and instant offer issuance.

Core Objective

Why CareerSphere Was Built

Traditional ATS (Applicant Tracking Systems) rely on rigid keyword matching and manual recruiter shortlisting. CareerSphere solves this by introducing autonomous LLM agents that analyze resumes contextually, generate tailored assessment rounds, conduct voice interviews, and proctor tests in real-time.

Key USP

What Makes It Unique

  • Autonomous AI Voice Interviewer: Real-time Speech-to-Text (Groq Whisper) and voice conversational evaluation.
  • Proactive Token Ticket Engine: Secure pre-generated attempt tokens for frictionless test access.
  • Multi-Agent Parity: Ingestion, Skill Matching, Proctoring, and Evaluation agents operating in sync.

2. End-to-End System Workflow

Here is the exact step-by-step lifecycle of how a job session and candidate application move through CareerSphere:

Recruiter Creates Job Session

The recruiter creates a new Job Session specifying the position, experience, location, and required skills. They configure custom SessionRounds: MCQ, Coding, and AI Voice Interview with custom passing score thresholds (e.g. 50%).

Candidate Applies & Resume Ingestion Agent Runs

The job seeker uploads their PDF/Docx resume. The Ingestion & Parsing Agent parses contact info, education, work experience, and normalized skills. The Match Agent calculates a hybrid Match Score % against recruiter parameters.

Proactive Token Ticket Generation

As soon as a candidate applies or advances to a proctored assessment round, the system proactively generates a secure 32-character ApplicantRoundAttempt ticket with a valid access_token.

Diagnostic Waiting Room & Assessment Portal

The candidate enters /test/entry?token=.... They undergo hardware diagnostics (webcam preview and live microphone volume level test). Once verified, they launch the test.

Multi-Round Assessment Execution
  • Round 1 (MCQ): Shuffled questions, timer, auto-submit on expiry, proctoring tab-switch detector.
  • Round 2 (Coding): Live code editor, instant test case execution.
  • Round 3 (AI Voice Interview): Interactive voice host, Groq Whisper transcription, live voice wave visualizer, real-time response evaluation.
Automated Evaluation & Auto-Progression

When an assessment is completed, the auto_progress_candidate pipeline evaluates candidate score against passing_score. If score >= passing_score, candidate status updates to shortlisted, auto-advances current_round_index, and notifies candidate in-app.

Recruiter Review, Forward & Offer Issuance

Recruiters can manually forward candidates at any time. In the final round, recruiter clicks "Hire Candidate", uploads the official Offer Letter (PDF/DOCX), and the candidate accepts in their dashboard.

3. Multi-Agent AI System Architecture

CareerSphere breaks down complex recruitment responsibilities into 4 specialized AI Agents:

Agent 1

Resume Ingestion & Parsing Agent

Responsibility: Extracts structured JSON data from raw binary resume files (PDF/Docx). Normalizes skills into canonical tags (e.g. "ReactJS" -> "React").

Tools: PyPDF2, python-docx, Regex heuristics, Gemini/OpenAI Schema Extractor.

Agent 2

Candidate Skill Matching Agent

Responsibility: Computes candidate-to-job compatibility score (0-100%). Weighs matched skills, experience delta, and location proximity.

Output: match_score, matched_skills, missing_skills, and AI qualitative recommendation.

Agent 3

Proctoring & Assessment Agent

Responsibility: Monitors candidate behavior during online rounds. Detects tab switches, lost focus, and audio anomalies during assessments.

Features: ProctoringFlag model, tab switch counter, audio waveform telemetry.

Agent 4

AI Voice Interviewer Agent

Responsibility: Conducts conversational voice interviews. Uses Groq Whisper (whisper-large-v3-turbo) for audio transcription and LLMs to grade technical accuracy, depth, and communication confidence.

1. Proactive Token Ticket System

Instead of generating test URLs lazily when a seeker clicks a button, the system proactively generates 32-character secure random tokens in ApplicantRoundAttempt upon round promotion, eliminating 401/403 race conditions.

2. Voice Activity Detection (VAD) & Live Transcript

In the AI Interview, real-time WebSpeech Speech-to-Text updates a Live Mic Transcript box on screen so the candidate sees their words live, while Groq Whisper transcribes the raw WebM audio upon candidate submission.

6. Expected Viva Questions & High-Score Answers

Prepare these top 8 viva questions to answer any technical or architectural question confidently:

Q1. What is CareerSphere, and what problem does it solve?
Answer: CareerSphere is an autonomous multi-agent recruitment platform. Traditional hiring processes suffer from manual resume screening delays and un-proctored static tests. CareerSphere automates candidate matching using multi-agent LLM parsing, conducts proctored technical & coding rounds, and hosts an interactive AI Voice Interviewer that grades candidates on technical accuracy, communication skills, and confidence in real-time.
Q2. How does the AI Voice Interview work under the hood?
Answer: The AI Voice Interview combines WebRTC getUserMedia for audio stream capture, browser WebSpeech API for live on-screen transcript rendering, and Groq Whisper API (whisper-large-v3-turbo) for high-fidelity audio transcription upon answer completion. The transcribed text is sent to the InterviewAgent LLM, which evaluates technical accuracy, communication quality, and confidence score, returning instant feedback and TTS speech.
Q3. How do you prevent candidates from skipping rounds or cheating?
Answer: We enforce security at three levels: 1) Token Ticket Authorization: Test URLs use 32-character random secure tokens. 2) Round Order Validation: In validate_test_token, the backend checks if the candidate has cleared all preceding rounds before granting entry. 3) Proctoring Telemetry: We log tab switches, window blur events, and microphone volume anomalies into ProctoringFlag records.
Q4. How does the system calculate the Resume Match Score?
Answer: The Skill Match Agent extracts normalized skills from the candidate resume and compares them against the job session's inferred skills. It computes a weighted percentage score based on matched core skills, experience level, and location compatibility, producing detailed breakdowns of matched_skills, missing_skills, and qualitative fit recommendations.
Q5. What happens when a candidate passes an assessment round?
Answer: When a candidate completes a test, auto_progress_candidate checks their score against the round's passing_score. If score >= passing_score, the system updates candidate status to shortlisted, increments current_round_index, generates the next round's token ticket, and sends an in-app notification to the seeker.
Q6. Can a recruiter manually override round results?
Answer: Yes! The recruiter acts as the administrator. In the recruiter workspace (`CandidateCard.jsx`), recruiters can manually click "Forward →" to advance any candidate to the next round at any time, or click "Hire Candidate" to issue an official offer letter PDF.
Q7. How is the frontend and backend integrated?
Answer: The frontend is built with React.js (Vite) and communicates with a Django REST API using clean Axios HTTP endpoints. State management handles candidate cards, stage filters, waiting room diagnostics, live video streams, and proctored assessment timers seamlessly.
Q8. What database models power CareerSphere?
Answer: Key models include: Company (recruiter entity), Session (job listing), SessionRound (round parameters & passing score), Candidate (applicant details & match score), JobApplication (seeker application status), and ApplicantRoundAttempt (proctored attempt data, token, scores, and interview transcripts).
